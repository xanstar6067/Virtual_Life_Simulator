# Темы оформления

`source/Theme.h` содержит описание цветов и выбранную тему приложения в namespace
`vlsui`. Classic и CyberBiology3 используют один экземпляр; смена мира или движка
не должна сбрасывать выбор. Доступны прежняя тёмная тема (по умолчанию) и первая
светлая тема с зелёными акцентами. Меню: вкладка «Ещё» → «Оформление» → «Тема».
Выбор действует до закрытия приложения; при следующем запуске используется тёмная тема.

## Состав и применение

- `Theme::imguiColors` — полный набор стандартных цветов ImGui.
- `Theme::implotColors` — цвета ImPlot; значение `IMPLOT_AUTO_COL` позволяет
  фонам, осям и надписям следовать соответствующим цветам ImGui.
- `Theme::palette` — именованные цвета дополнительных элементов: уведомлений,
  кнопок действий, подписей питания, рядов графика, нейронов и связей мозга,
  фона SDL и журнала.
- `MakeDefaultTheme()` и `MakeLightTheme()` создают полные описания без UI-контекстов.
- `Theme::id` / `ThemeName()` определяют название выбранного оформления в меню.
- `DrawThemeMenu()` из `UITheme.h` — общий список выбора для обоих движков.
  Он вызывает `RequestTheme()`, а `SDLBeginScene()` применяет ожидающий выбор
  через `ApplyPendingTheme()` перед очисткой следующего кадра. Так смена цветов
  не пересекается с активными окнами и PushStyleColor/PopStyleColor.
- `GetTheme()` и `Palette()` предоставляют доступ только для чтения.
- `ApplyTheme(theme)` сохраняет собственную копию и применяет цвета к существующим
  контекстам. Вызывать из UI-потока между кадрами, вне PushStyleColor/PopStyleColor.
- `InitializeTheme()` из `UITheme.h` задаёт геометрию стиля и применяет выбранные
  цвета при создании UI-контекстов. Для смены цветов достаточно `ApplyTheme`.

Размеры, отступы, скругления, шрифты и расположение панелей заданы отдельно.
Тема не входит в бинарный формат мира и не изменяет правила симуляции.

## Добавление палитры

Создайте фабрику, возвращающую `Theme`, на основе `MakeDefaultTheme()`. Задайте
стандартные цвета и дополнительные семантические цвета явно; поля palette не
пересчитывают массивы ImGui автоматически. Например, акцент кнопки и цвет
ползунка могут различаться:

```cpp
auto theme = vlsui::MakeDefaultTheme();
theme.palette.accent = ImVec4(.35f, .25f, .65f, 1);
theme.palette.accentHovered = ImVec4(.45f, .35f, .75f, 1);
theme.palette.accentActive = ImVec4(.25f, .15f, .55f, 1);
theme.imguiColors[ImGuiCol_CheckMark] = theme.palette.accent;
theme.imguiColors[ImGuiCol_SliderGrab] = theme.palette.accent;
vlsui::ApplyTheme(theme);
```

При добавлении элемента интерфейса используйте цвета стиля ImGui либо именованное
поле palette. Новые декоративные RGB-литералы размещайте в описании темы.
Цвета объектов поля, наследуемые цвета ботов, карты энергии/питания и параметры
океана/ила остаются данными визуализации движков. Цветовой образец выбранного
бота также берётся из самого бота.

## Проверка

Запустите `tests/Run-UIWorkspaceSmoke.ps1`: он собирает приложение Debug x64 и
проверяет реальный интерфейс обоих режимов через SDL software renderer.
Проверка смены темы включает фон SDL, отсутствие изменения отступов и тиков,
цвета ImPlot и сохранение выбора при пересоздании контекстов. Изображение пробной
палитры — `x64/Debug/ui-smoke-<mode>/theme-probe.png`.

Меню проверяется в обоих режимах при широком и компактном размере: открытие
списка, выбор светлой и возврат тёмной темы, сохранение мира/выделения/тика и
отступов. Превью: `wide-light-menu.png`, `compact-light-menu.png` и
`compact-light-brain-chart.png` внутри каталогов тестов каждого режима.
